# Datos

- **Dataset original:** no se incluye porque pesa 285 MB (GitHub admite hasta 100 MB por archivo). Se descarga desde Kaggle al ejecutar el notebook del TP:

- **`steam_reviews_clean_sample.zip`:** muestra estratificada de 50 000 reseñas del dataset final (limpio) de 733 juegos. Es la base de todos los modelos del notebook del TF.
